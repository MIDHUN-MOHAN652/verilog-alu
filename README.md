# Parameterized Digital System using Verilog

## Overview
This project implements a parameterized digital system in **Verilog**, consisting of a datapath (ALU) and a control unit (FSM), integrated through a top-level module.

The design demonstrates **separation of control and datapath**, multi-cycle operation using an FSM, and systematic verification using simulation and waveforms.

This project is intentionally kept in **pure Verilog** to focus on fundamentals. SystemVerilog is planned for future projects.

---

## Architecture
The system is composed of three main blocks:

- **ALU (Datapath)** – performs arithmetic and logical operations
- **FSM Controller (Control Unit)** – sequences operations across clock cycles
- **Top Module** – integrates control and datapath into a single system

Control signals (`load`, `execute`, `done`) are generated by the FSM and used to manage timing and data validity.

---

## Modules

### ALU
- Parameterized data width
- Supported operations:
  - ADD, SUB
  - AND, OR, XOR
  - SHIFT LEFT, SHIFT RIGHT
  - ZERO output
- Generates status flags:
  - Zero
  - Carry
  - Negative
- Fully combinational design

---

### FSM Controller
- Moore finite state machine
- States:
  - IDLE
  - LOAD
  - EXECUTE
  - DONE
- Controls operation sequencing
- All outputs are mutually exclusive and glitch-free
- Synchronous reset supported

---

### Top Module
- Integrates FSM and ALU
- Defines the system-level interface
- Exposes `done` signal to indicate when ALU output is valid
- Structural integration only (no hidden logic)

An extended version with registered inputs and outputs is included to demonstrate true multi-cycle datapath behavior.

---

## Verification Strategy
Verification is performed at **three levels**:

### 1. ALU Verification
- Independent self-contained testbench
- Arithmetic, logical, and boundary cases tested
- Flag behavior verified
- Waveform inspection used to validate combinational behavior

### 2. FSM Verification
- Dedicated FSM testbench
- Verified:
  - Reset behavior
  - Correct state sequencing
  - Single-cycle assertion of control signals
  - Robust behavior against improper `start` usage

### 3. System-Level Verification
- Top-level testbench verifies:
  - End-to-end control + datapath flow
  - Correct timing of `done` signal
  - Stable ALU output when `done` is asserted
- Waveforms generated and inspected using GTKWave

This layered verification approach ensures correctness beyond single test cases.
